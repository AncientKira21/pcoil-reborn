# Quilt

Real Quilt entrypoints using Quilt Loader Fabric compatibility. The JAR bundles the Fabric hook implementation and Common runtime; install with compatible Quilt Loader and regular Fabric API.

From the project root: `./gradlew :quilt:build` or
`./gradlew -PmcVersion=26.3 :quilt:build`. Output: `quilt/build/libs/`.
See the root README for all versions, dependencies and verification limits.
