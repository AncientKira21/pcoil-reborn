# Fabric

Real Fabric entrypoints, tick/creative-tab callbacks, networking and rendering hooks. Common classes and resources are bundled into the mod JAR.

From the project root: `./gradlew :fabric:build` or
`./gradlew -PmcVersion=26.3 :fabric:build`. Output: `fabric/build/libs/`.
See the root README for all versions, dependencies and verification limits.
